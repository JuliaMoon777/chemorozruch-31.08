# CHEMOROZRUCH — Website Redesign

Premium one-page industrial website for CHEMOROZRUCH.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Preview

```bash
npm run preview
```

## Stack

* React 19
* Vite 6
* TypeScript
* Tailwind CSS
* GSAP & ScrollTrigger
* Lucide Icons

## Deployment

The repository is prepared for deployment on Vercel.
